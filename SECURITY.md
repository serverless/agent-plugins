# Security

To report a security issue in this plugin or in the Serverless Framework, open a private report on the [security advisories page of the Serverless Framework repository](https://github.com/serverless/serverless/security/advisories/new). Don't report security issues in public GitHub issues.

The plugin holds instructions for AI coding agents and the manifests that let agents install them. It contains no hooks, no MCP servers and no executables, and nothing in it runs on your machine.
